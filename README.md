# Alicia's Teeth Gemz Website

Static website for Alicia's Teeth Gemz.

## Files

- `index.html` - main website
- `style.css` - design, layout, and animation
- `script.js` - tab switching and image preview
- `assets/` - flyer and price images

## How to Open

Open `index.html` in a browser, or open this folder in VS Code and use a local preview extension.

## Later GitHub Pages Setup

When ready, upload the folder to GitHub and enable GitHub Pages from the repository settings.
